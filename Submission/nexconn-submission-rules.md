## 1. Overview

- **Name:** Nexconn Build Challenge 2026
- **Format:** Fully online hackathon
- **Core requirement:** Build a real-time, chat-driven app using the **Nexconn Chat SDK** (or Chat UI).
- **Optional:** The Nexconn **Call SDK** (voice/video) — not required, but can be used.
- **Cost:** Free to enter.
- **Tagline:** "Build a real-time chat-driven app with the Nexconn Chat SDK."

## 3. Eligibility

- Open to **any developer, designer, or student**.
- **Exception:** Residents of **Mainland China** are not eligible — the Nexconn Free Chat Plan (part of the prize) is not available there.
- No cost to participate.

---

## 4. Teams

- Team size: **1–4 people** (solo participation allowed — create a "team of one" on your dashboard).
- The **team leader**:
  - Registers the team
  - Selects the track
  - Submits the final entry on behalf of the team

---

## 5. Building Rules

- **Must use:** Nexconn Chat SDK or Nexconn Chat UI (required — this is the one hard rule).
- **Optional:** Nexconn Call SDK (voice/video).
- **Theme/use case:** Open — the challenge lists example areas, but you can build anything real-time as long as it genuinely uses the Nexconn Chat SDK.
- **Prior work / existing projects:**
  - Allowed, **but** you must add a real, new Nexconn integration during the challenge window (Oct 23 – Nov 22, 2026).
  - You must clearly disclose in your write-up which parts existed before the challenge and which parts were built specifically for it.
- **Account requirement:**
  - Create a **free Nexconn account** (separate from your Reskilll account).
  - Create an app in the **Nexconn Console** and copy its **App Key**.
  - Include this App Key in both your write-up and your submission form — judges use it to verify actual SDK usage.
- **Platforms supported:** Web, iOS, Android, Flutter (via the respective Nexconn ChatUI SDKs), plus a Go server SDK for backend work.

---

## 6. What to Submit

By the deadline (Nov 22, 23:59 AoE), each team must submit:

1. **Write-up (PDF)** — including your Nexconn App Key
2. **Demo video**
3. **Runnable app link**
4. **Public GitHub repo**
5. **Traction proof** — optional, bonus points

## 8. Platform / SDK Notes (context, not strictly "rules")

- The Nexconn Chat SDK & Chat UI are free for up to **10,000 monthly active users (MAU)** for one year on the Free Chat Plan.
- Official SDK repos (GitHub, NexconnAI-Dev):
  - `nexconn-chatui-web`
  - `nexconn-chatui-ios`
  - `nexconn-chatui-android`
  - `nexconn-chatui-sdk-flutter`
  - `nexconn-server-sdk-go` (and community SDKs for Python/PHP also exist)
  - `nexconn-skills` — an AI coding-assistant integration skill (`npx skills add https://github.com/NexconnAI-Dev/nexconn-skills.git --skill nexconn-chat`)
